## 3. 测试实现及真实性边界

### 真实执行的部分

- 每个用例新建隔离环境，加载完整的 `D:\Omite\content.js`，不是把生产函数复制成另一份实现。
- 同时加载真实 `D:\Omite\background.js`，按其 `importScripts` 加载权限与 API 辅助库。
- 内容脚本依赖按 manifest 中的清单读取，真实执行 MD5 与 `D:\Omite\libs\font-table.js` 的编码、解码、查找和 JSON 回退逻辑。
- 字体入口通过在**内存源码**的 IIFE 尾部附加只读测试引用暴露；磁盘上的生产文件不修改。暴露 `getDecryptTable`、`buildDecryptMapForDoc`、`decryptSecretFontsInDocument` 三个入口，不修改其函数体。
- 日志从真实 `runtime_log` 消息监听器进入；作用域授权走真实 Worker。当前日志追加本身仍是 content 侧直接读写 storage，这正是要验证的共享写入问题。
- 两个/三个页面上下文共享模拟存储，但各自有独立变量、队列与页面身份。读取时复制快照，固定能触发丢更新的合法并发时序，避免依赖随机调度碰运气。
- 完成时重新读取已使用的源码文件校验哈希，防止跑测试期间外部修改文件导致证据失配。

### 被模拟的部分

- DOM 为最小对象夹具，不是浏览器 DOM；没有启动真实 MutationObserver 自动扫描，通过字体入口明确触发扫描。
- Typr 字体解析与字形轮廓是可控替身，两种字体、两个私用区字符作为夹具；没有把一字节字体标记冒充有效 TTF。
- 字形哈希使用真实 MD5，二进制映射表由真实编解码库在内存生成，不改动现有资源表。
- `fetch` 只允许两个扩展资源 URL 进入模拟响应，其余请求直接令测试设施报错；Worker 不允许发出真实网络请求。
- Chrome 存储与标签 API 被打桩。存储错误/回调丢失是故障注入，不代表已经在用户浏览器观察到同样故障频率。
- DOMContentLoaded 自动启动保持未触发，避免测试字体/日志时顺带启动 UI、任务调度或其他网络逻辑。

因此，这些是执行真实生产逻辑的隔离回归用例，但不是这三个缺陷在真实 Edge/真实学习通页面的端到端证明。未来修复字体和日志后，仍需真实浏览器补充验证。

### 时间约定

- 虚拟时钟执行生产逻辑实际注册的定时器，并让 Promise 微任务完成，不靠机器快慢或长时间 sleep。
- 恢复/挂起测试预算为 **120,000 虚拟毫秒**：这是本轮验收约定，不是生产代码已有的超时，也不要求未来实现恰好等待两分钟。
- 单用例另有 8 秒真实时间防挂死上限。生产流程未在虚拟预算内完成算行为失败；真实时间防线触发算测试设施错误。
- 当前挂起路径没有期限，推进虚拟时间后仍无法结束，不能把这一现象解释成“实际等了两分钟”。

## 5. 测试自身的验证

1. 虚拟时钟边界：19ms 不触发 20ms 的回调，推进到 20ms 才触发。
2. 永远 pending 的 Promise 会明确失败，不会被跳过或当成空值通过。
3. 注入锚点不存在/出现多次，测试自检必须失败。
4. 四组“正常实现先通过 → 内存注入已知错误 → 同一行为断言失败”：
   - F01：取消字形映射，断言转换后的明文失败。
   - L02：取消 JSON 回退，断言解码结果失败。
   - G01：取消日志追加，断言最终记录列表失败。
   - G04：取消容量截断，断言长度为 200 失败。
5. 注入之前检查唯一锚点和源码变化，检查位于 `assert.rejects` 外；之后确认修改后的 content 确实被执行，并核对失败断言的 expected 值，避免“锚点错误也算捕获”的假绿。
6. 故意提供无效内存源码，确认分类为测试适配/装配错误，不误判为行为回归。

这些验证全部在内存进行，未临时改坏磁盘上的生产文件。

命令行额外实测：F01 单例退出 0；不存在的用例、错误分组、相对 `--root` 路径均退出 2；日志分组列出 10 个用例。
