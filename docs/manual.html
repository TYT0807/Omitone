"扩展"是什么。它是一个装进浏览器里的小程序，装完之后浏览器右上角会多一个按钮。 它不像普通软件那样有安装向导、有桌面图标 —— 它平时是看不见的，只有你点那个按钮，或者打开学习通页面时，它才露面。 所以"装完了却觉得什么都没发生"是正常的。

"压缩包"要解压，是个高频坎。你从网上下回来的那个 omitone.zip 不能直接交给浏览器。要先用鼠标右键点它，选「全部解压缩」（有的系统叫「解压到当前文件夹」）， 得到一个和它同名的文件夹。浏览器要的是那个文件夹，不是压缩包。 这一步做错的表现是：浏览器报“清单文件缺失”或干脆没反应。

第 1 步　下载并解压

① 你会看到什么 浏览器打开了项目首页，最上面有两个大链接。左边那个写着 「点我下载插件（omitone.zip）」。
② 点哪里 点它。浏览器会下一个文件，通常是 omitone.zip， 落在你的「下载」文件夹里。
下完之后，用鼠标右键点这个 zip 文件 → 选「全部解压缩」。
③ 怎样才算对 解压出来的文件夹里，直接就能看到一个叫 manifest.json 的文件。
（看不到文件后缀？在文件夹里点「查看」→勾上「文件扩展名」。）
④ 不对怎么办 如果你解压后看到的是又一个压缩包，说明你只解开了外面一层，再解压一次。
如果文件夹里是另一个同名文件夹，要进到最里面那一层， 直到眼前直接摆着 manifest.json。
把解压出来的文件夹放到一个你不会随手挪动的位置（比如 D:\omitone\）—— 放桌面然后手滑拖进垃圾桶，扩展就会失效。

第 2 步　打开扩展管理页

① 你会看到什么浏览器顶部那条输入网址的栏。
② 点哪里 点进地址栏，输入下面这串，回车：
用 Edge：edge://extensions
用 Chrome：chrome://extensions
③ 怎样才算对 出现「已安装的扩展」列表页。你现在装过的东西会列在这里， 页面左下角（Edge）或右上角（Chrome）有个开关。
④ 不对怎么办 如果这串地址被当成搜索词搜出去了，说明你没输全、或者多打了空格。完整复制粘贴最稳。
如果你用的是别的浏览器：Firefox 不支持本扩展； 国内套壳浏览器（QQ / 360 / 搜狗）没有开发者模式，也用不了。

第 3 步　打开开发者模式

① 你会看到什么 刚刚那个扩展管理页。页面左下角（Edge）或右上角（Chrome） 有一个叫「开发人员模式 / 开发者模式」的拨动开关，现在是灰的。
② 点哪里点一下那个开关，让它变蓝/变亮。
③ 怎样才算对 页面顶部长出三个新按钮：「加载解压缩的扩展程序」、 「打包扩展程序」、「更新」。
④ 不对怎么办 找不到这个开关，多半是页面没滚到顶 —— 它固定在左上角/右上角。 实在没有，说明你用的不是 Edge 或 Chrome。

第 4 步　加载扩展

① 你会看到什么页面上已经出现「加载解压缩的扩展程序」这个按钮。
② 点哪里 点它 → 会弹出一个"选择文件夹"的窗口 → 选中第 1 步解压出来的那个文件夹 （就是里面能直接看见 manifest.json 的那一层）→ 点「选择文件夹」。
③ 怎样才算对 列表里多出一张卡片，名字是 Omitone-1.1.6，下面写着 「支持学习通视频播放、API 自动答题」，右下角是「已启用」。
④ 不对怎么办 报「清单文件缺失」→ 你选错层了，选到了压缩包或它的上一级，退回去重选。
报「无法加载扩展程序」→ 看看文件是不是被解压软件放进了临时目录 （比如 AppData\Local\Temp），挪到普通目录再试。
报「清单文件无效」→ 文件可能在下载或解压时损坏了，重新下一遍。
装完先确认一件事：它要"在所有网站上运行"是正常的

卡片上会出现这条提示，不要关掉它，也不要觉得这是权限滥用 —— 验证码有时会弹在与学习通无关的独立网址上。 扩展在其它网站上检测到不是目标页面会立刻静默退出，什么都不做。

到这里就装完了。现在去做什么？

打开任意一门学习通课程页面，右下角会出现一个 Omitone 面板。 看到它 = 装对了。接下来点「开始运行」就能刷课， 不需要 API Key（要 AI 答题才需要，见第 3 章）。

1. 这是什么，能替你做什么

Omitone 是一个装在浏览器里的扩展。它替你处理学习通网页版里那些 纯粹消耗时间的部分：视频要播完、PPT 要翻到最后一页、讨论区要留一句言、 章节测验要答完。

它不会替你登录，也不会替你发布任何内容 —— 除了你自己开启的讨论区自动回复。 所有数据都在你本机，项目没有任何服务器。

功能说明需要 API Key
视频 / 音频自动播放自动开播、被暂停自动抢回、播完自动翻节不需要
自动最大倍速读播放器菜单取速度上限；读不到就逐档试探不需要
拖到结尾可拖动的视频直接跳到片尾，每个视频只试一次不需要
PPT / 文档 / 图片自动翻页并上报完成不需要
讨论任务点跳转讨论区 → 自动回一句 → 返回继续刷课不需要
跳过不必做的点老师没设为任务点的内容直接跳过不需要
题库字体反爬还原学习通用自定义字体加密过的题目文字不需要
AI 答题单选 / 多选 / 判断 / 填空 / 简答 / 视频内弹题需要
验证码识别抓图交给视觉模型识别后自动填入需要（且必须是视觉模型）
没有 API Key 也完全能用

上面标"不需要"的功能装了就能跑。没有 Key 时遇到测验会跳过不答，其余照常。

2. 安装（逐步版）

第 0 章已经走过一遍了。这里是同一件事的详细版： 多讲一些"为什么"和边角情况。已经装成功的同学，直接跳到第 3 章。

  1. 下载并解压 打开项目首页，点最上面那个「下载插件」按钮，会直接下到一个 omitone.zip。 然后右键 → 全部解压缩，解到一个不会被轻易挪动的目录。
    千万别双击压缩包就直接加载 —— 浏览器要选的是解压后的文件夹， 不是压缩包，也不是压缩包里的预览。解压后的文件夹里应该能直接看到 manifest.json。
  2. 打开扩展管理页 Edge 输入 edge://extensions；Chrome 输入 chrome://extensions。
  3. 打开开发者模式 页面左下角（Edge）或右上角（Chrome）的「开发人员模式 / 开发者模式」开关。
  4. 加载解压缩的扩展程序 点该按钮，选中解压出来的那个文件夹（里面直接就是 manifest.json 与 page.js）。选中后列表里会出现 Omitone。
  5. 确认它要"在所有网站上运行"是正常的 这不是权限滥用 —— 验证码有时会出现在与学习通无关的独立网址上。 扩展在其它网站上检测到不是目标页面会立刻静默退出，什么都不做。
装完之后：改代码 / 更新版本要「重新加载 + 刷新页面」

在扩展管理页点一下 Omitone 上的「重新加载」，然后务必刷新学习通页面（F5）。 只重载扩展不刷新页面，页面里旧的脚本会与扩展断连，症状是"功能全停、日志不动"。

3. 第一次配置

打开任意学习通页面，页面右下角会出现一个 Omitone 面板（也可以点浏览器工具栏上的扩展图标打开设置弹窗）。

3.1 设置弹窗长这样

弹窗从上到下分三块：顶部是运行状态和开始/停止； 中间是六个可以折叠的分组（播放、任务点、任务点类型、答题、讨论任务点、AI 接入）； 底部是查看日志、恢复默认这类次要操作。

① 你会看到什么 点浏览器工具栏上的 Omitone 图标，弹出这个面板。顶上写着 「未开启」，下面是一排折叠的分组。
② 点哪里 先不要改任何开关。这一步只是"认地方"。
想改设置时，点分组的标题（比如「播放」）就能展开或收起。
③ 怎样才算对 你能一眼分辨出：哪个分组标着「不需 Key」、哪个标着 「需要 API Key」。只有标「需要 Key」的才要你填东西， 其余保持默认即可。
④ 不对怎么办 点图标没反应 → 回第 2 章第 4 步，检查扩展卡片是不是「已启用」。
弹窗打开了但一片空白/错乱 → 在扩展管理页点「重新加载」， 然后刷新学习通页面。
面板太窄/字太小 → 那里是浏览器窗口宽度决定的，可以拉宽浏览器窗口。

3.2 拿到一个 API Key

这一步只在你想要 AI 答题时才需要。只想刷课的话，跳过整节去第 4 章。

  1. 去 DeepSeek 开放平台注册 打开 platform.deepseek.com，注册并登录。
  2. 充值一点点就够 这个工具每次答题消耗的是输入 token 为主，一节测验通常只花几分钱。 充 10 元能用很久很久。
  3. 创建 API Key 在「API keys」页面新建，复制那串 sk-…。 它只在创建时显示一次，复制好再关页面。
  4. 回到扩展弹窗，粘贴进去 输入框失焦后会自动保存，不需要再点别的按钮。粘贴时带上引号或 Bearer 前缀也没关系，会被自动清洗掉。
  5. 点「检测 API 连接」 看到成功提示说明通路正常。这一步别跳过 —— 它是唯一能在真正答题前发现问题的机会。
① 你会看到什么 DeepSeek 网站的 API keys 页面，表格里有一列是密钥，通常被遮成 sk-••••••，旁边有个复制图标。
② 点哪里 点「创建 API Key」（或 Create new API key）→ 它会完整显示一次那串 sk- 开头的字符串 → 点复制按钮。
然后回扩展弹窗，展开「AI 接入」分组，粘贴进 API Key 那一格。
③ 怎样才算对 粘贴后不用点保存（它自己就存了）。接着点 「检测 API 连接」，出现成功/绿色的提示 = 通了。 看到成功提示才算这一步真的做完。
④ 不对怎么办 「密钥无效 / 401」 → 复制时多带了空格、少复制了尾巴，或者这个 Key 已经被删了。
「余额不足 / 402」 → 去平台充值。新号一般不送额度。
「连接超时」 → 网络问题，换个网络或稍后再试。
什么都不填也点检测 → 会提示你要先填 Key，这是正常的。
还有一个隐蔽的坑：弹窗里那格是密码框，显示的是圆点， 看不出对错。真怀疑粘错了，重新粘一遍比盯着看更快。

其他服务商的密钥在哪申请（申请流程都一样：注册 → 充值 → 建 Key → 粘贴）：

密钥等于你这张"话费卡"的密码。项目没有任何服务器，密钥只存在你本机的浏览器里、 只发给你填的那家服务商，扩展作者看不到也拿不到。 但请务必在自己的账号里给它设一个消费上限，并且不要在截图、 聊天记录里露出完整的密钥。详见第 8 节。

3.3 想用别的模型怎么办

除了 DeepSeek（唯一在真实答题里完整验证过），现在也预置了 Kimi（Moonshot）、通义千问（DashScope）、Anthropic Claude、 Google Gemini。要提醒的是：后四家的地址与模型名是按厂商文档填的快照， 没有在真实题库上跑过，下拉框里也如实标了「未实测」。

服务商API URL（选好预设会自动填）模型名（快照）
DeepSeekhttps://api.deepseek.comdeepseek-v4-flash
Kimihttps://api.moonshot.ai/v1
（国内站是 api.moonshot.cn）		kimi-k3
通义千问https://dashscope.aliyuncs.com/compatible-mode/v1
注意地址里那段 compatible-mode 不能少		qwen3.8-flash
① 你会看到什么 「AI 接入」分组里的「接入方式」下拉框，点开是一串预设： DeepSeek / Kimi / 通义千问 / Claude / Gemini / 自定义 OpenAI 兼容。
② 点哪里 点你要用的那一家。API URL 和模型名会自动填好，你不用手打。 然后只需要把对应那家的 API Key 粘进去。
③ 怎样才算对 API URL 那格自己出现了地址（不是你手输的）， 模型名那格自己出现了模型名。然后点「检测 API 连接」能成功。
④ 不对怎么办 换了一家但地址没变 → 你只点了下拉框没选到项，重新点一次选中它。
报「模型不存在」→ 这家的模型名过期了（见下面的说明框）， 只要改「模型名」那一格，地址不用动。
报「地址不对 / 404」→ 国内站和国际站搞混了（Kimi 尤其容易： .cn 与 .ai 是两个不同的站）。

表里没有的服务商（智谱 / OpenRouter / 硅基流动 / 各种中转站 …）请选 「自定义 OpenAI 兼容」，把官方文档上的 API 地址与模型名自己填进去 —— 只要对方兼容 OpenAI 的 /chat/completions，填什么都能用。

为什么预置的模型名会过期？过期了怎么办？

预置里的模型名是钉死的快照，厂商一发新版它就会失效。 失效的表现通常是报"模型不存在"，改「模型名」那一格即可 —— API 地址与协议一般不会变。项目里有一份 docs/channels.md 记录着各家地址、模型名与最后核对日期， 也会定期跟着更新。

3.4 思考强度：三档，默认关掉

弹窗里有一个「思考强度」下拉框，只有三个选项。默认是「关闭」，建议保持。

档位给厂商发什么什么时候选它
关闭（默认） DeepSeek 发 thinking:disabled；通义发 enable_thinking:false； 其他一律不发任何参数 几乎总是选它。答题是模式化任务，不需要推理 —— 实测一次请求从 361 token 降到 133，又快又省
低 reasoning_effort: low 题目偏难、明显感觉答得不准时，可以试试
高 DeepSeek high；通义 xhigh；Kimi max 基本不需要。每道题都会先烧掉一大段推理 token，账单会明显变高
诚实说明：只有「关闭」是实测过的

三档里只有「关闭」在本项目一直被真实使用（那是升级前的唯一行为）。 「低」「高」的参数是照各家官方文档写的，没有在真实题库上验证过： 有的服务商会直接拒绝不认识的参数。真被拒绝时程序会 自动摘掉参数重试一次并把原因写进日志，不会让答题功能整个失效 —— 但既然没必要多花钱，默认关着就好。

另外 Kimi K3 是恒思考模型，关不掉。选「关闭」不会报错，但它仍然会推理。 弹窗里那句"当前实际发送"会如实告诉你这一档到底发了什么。

4. 开始刷课

这一步是整个工具的主干。装好、配好之后，剩下的时间它都在做这件事。

① 你会看到什么 浏览器里已经打开了某门课的章节页面。点扩展图标，弹窗顶部写着 「未开启」，那个小圆点是灰的。
② 点哪里 先确认「播放」和「任务点」这两组里的开关保持默认（开着的）， 然后点顶部那个蓝色的「开始运行」。
③ 怎样才算对 两处同时变化：
① 弹窗顶部由「未开启」变成 「运行中」，圆点变绿色；
② 学习通页面右下角冒出一个状态浮窗。
然后视频自己开始播 —— 到这一步它就在干活了。
④ 不对怎么办 点了没反应、圆点还是灰的 → 最常见的两种： 没刷新学习通页面（按 F5），或者当前页面根本不是课程页 （在首页、作业页、考试成绩页它是不会启动的）。
圆点绿了但视频不动 → 点「查看日志」，看最后几行有没有报错， 拿日志里的原话去第 7 章对照。
开始之后又自己变回"未开启" → 多半是页面被跳转/刷新过， 扩展会重新接管，稍等十几秒；一直不行就刷新页面重来。
  1. 打开课程页面进入你要刷的那门课，停在章节列表或任意一节课里。
  2. 点扩展图标 → 确认开关 → 点「开始运行」右下角会出现状态浮窗。
  3. 然后就可以去干别的了它自己会：播放视频 → 做文档 → 答题 → 下一节。
  4. 想停就点「停止」或者直接关掉标签页。
出问题先看日志

点扩展图标 →「查看日志」，里面是最近 200 条运行记录。 90% 的问题看一眼日志就能定位，比反复猜测快得多。页面右下角浮窗只有摘要， 想看全的就去日志面板。

① 你会看到什么 弹窗底部有一行小字按钮，写着「查看日志」。 点下去，弹窗下面展开一个深色/灰底的记录区。
② 点哪里 点「查看日志」。里面每一行长这样： info llm prefix cache hit:180 miss:120 —— 开头是等级（info / warn / error）， 后面是英文的机器记录。
③ 怎样才算对 能看见行、而且最下面那几行是"刚刚"的 = 扩展还活着、还在往外吐记录。
如果你点了「开始运行」之后这里一个字都不增加， 说明扩展没接上页面 —— 刷新页面。
④ 不对怎么办 不知道某行什么意思 → 直接搜第 7 章的表格，里面有常见英文日志的中文对照。
日志刷屏太快看不清 → 点「停止」再看，日志会留着。

5. AI 答题是怎么工作的

理解这四步，你就知道它能做到什么、做不到什么：

  1. 抠题从页面 DOM 里把题干、选项、题型读出来。遇到字体反爬会先还原文字。
  2. 问模型把题目按 10 题一批打包发给你自己填的那个 API 地址，要求模型只回一个答案数组。
  3. 回填把答案写进页面选项与隐藏答案域。
  4. 交卷检查所有题都填上了才提交；判错会带着"已排除的错误答案"再来一轮。

5.1 关于正确率（重要）

AI 答题做不到全对，考试请不要用
  • 提示词要求"不确定也要给最可能的答案"，所以模型会猜，猜错就是真错。
  • 答错后会自动重试，但默认最多尝试交卷 20 次 —— 而这些提交是真的会交上去的。 如果这门课限制了提交次数，请先确认规则。
  • 判断题、多选题的出错概率明显高于单选题。
  • 成绩重要的测验，请在弹窗里关掉「自动答题」自己答。 这个工具的价值在于省下刷视频的时间，不在于替你拿分。

5.2 怎么知道钱花在哪了

日志里会出现 llm prefix cache hit:… miss:… 这样的记录。 DeepSeek 对重复出现的提示词前缀有缓存，命中部分按约十分之一的价格计费。

① 你会看到什么 日志里形如 llm prefix cache hit:180 miss:120 的行。
hit = 走了缓存（便宜）的 token 数； miss = 没走缓存的 token 数。
② 点哪里不用点，它自己会记。看日志时留意这一行就行。
③ 怎样才算对 hit 是个明显大于 0 的数字（比如 180 hit : 120 miss）， 说明省钱机制在工作 —— 那一部分按十分之一计价。
④ 不对怎么办 如果 hit:0 一直不变，说明前缀没被缓存识别 —— 那通常意味着提示词被改动过（把每次都变的内容放到了前面）。 这是 1.1.0 专门修过的问题，日志留在这里就是为了让你能一眼看出来。
只是账单偏高、但 hit 正常 → 看看是不是把"思考强度"开到了「高」， 那个档每道题都会先烧一大段推理 token。

6. 验证码

学习通会在检测到异常行为时弹验证码。开启「验证码自动识别」后，扩展会抓图、 交给视觉模型识别、再填进去。

  • 必须另填一个视觉模型名（例如 gemini-flash-latest、 qwen-vl-max 这类支持图片输入的模型）。留空会退回主模型， 大概率识别失败。
  • 识别并不总准，会重试，也可能识别错 —— 错了就是白跑一轮。
① 你会看到什么 学习通页面上突然弹出一个小窗口，里面是一张歪歪扭扭、带干扰线的字母数字图， 下面有个输入框。
② 点哪里 你不用点 —— 前提是你在「答题」分组里开了 「自动识别验证码」，并且填了「验证码识别模型」。 开了之后它会自己抓图、识别、填进去。
③ 怎样才算对 验证码窗口自己关掉，课程继续往下走， 日志里出现识别相关的记录。到这一步就是成功了。
④ 不对怎么办 它一直重试、填不对 → 大概率是"验证码识别模型"留空或填错了 —— 留空会退回主模型，而主模型多半看不了图。必须单独填一个能看图的模型。
你自己手动填一次 → 最快。填完继续刷课即可。
验证码越来越频繁 → 见下面的警告框，别硬刚。
验证码频繁出现，说明平台已经在关注自动化行为了

这时候最稳妥的做法是停一会儿，手动做几题，而不是继续硬刚。 继续跑只会让风控升级。

7. 常见问题排查

用法：先找最接近的症状那一行，照着"先查什么"做。 右边出现英文日志时，直接在下面这张表里搜那串英文。

症状先查什么
点了开始，什么都不动 先确认是不是没刷新页面（只重载了扩展）。刷新学习通页面再看日志第一行有没有 start。
AI 一直读不到题 ① 日志里有没有 quiz scan found 0 questions；
② 密钥是否真的保存上了（最常被忽略 —— 确认「检测 API 连接」能过）；
③ 是不是卡在标题含「作业 / 考试」的章节不动。
答案填了但不交卷 通常是有题没填上。看日志末尾几行有没有 answers are not ready。
视频里的弹题卡住不动 看日志里有没有 popup quiz unanswerable —— 那是"认不出的弹题模板，已放弃"。 这类题最多问 3 次就放手，课程会继续，不会卡死。
题干显示成乱码 立刻停手。这是题库字体反爬表过期了，乱码喂给 AI 必然答错，还白烧 token。
窗口最小化后几乎不动 浏览器自己的「睡眠标签页」是整页冻结，插件绕不过。去 edge://settings/system 关掉它。
某个任务点一直做不完 多看日志：遇到老师设成防拖拽 / 不可翻页的点，连续几次做不完会被记入"放弃名单"。
讨论区发了「1」 默认回复内容就是 1，请务必改成正常的话 —— 一串 1 在老师眼里就是灌水。

7.1 日志里的英文都在说什么

日志是英文的，因为它首先是给开发者看的。但其中最常出现的几行，你也能直接读懂 —— 知道它们在说什么，就基本能自己判断"是在正常干活"还是"真的坏了"。

日志里的字样它的意思 / 你该做什么
start 扩展开始工作了。看到它就说明"接上页面了"，是最好的第一信号。
llm prefix cache hit:… miss:… 这次请求花掉多少 token、其中多少走了便宜的缓存。属于正常记录。
quiz answers count: N 这一卷抠出并回答了 N 道题。N 与卷面题数一致就是对的。
quiz scan found 0 questions 一道题都没读到。要么这节不是测验，要么页面结构变了。
answers are not ready 还有题没填上，所以没有提交。这是保护动作，不是故障。
video paused unexpectedly, resuming 视频被人/网站暂停了，扩展正在抢回播放。属正常拉锯，不用管。
popup quiz unanswerable 视频里那种弹题认不出来，已放弃这一道。课程会继续走，不会卡死。
llm rejected thinking params, retry without them 这家服务商不认识"思考强度"那个参数，扩展自动摘掉后重试。已自愈。

7.2 给愿意动手的人：页面控制台诊断命令

在学习通页面按 F12，在控制台里可以直接查现场：

命令作用
xxtAI.diagnose()题目扫描诊断：每个框架命中了什么选择器、为什么没抠出题

8. 密钥安全：为什么说它偷不走

做这种工具最该被追问的就是这句话。所以把结论和你可以自己验证的方法都放在这里。

结论

密钥只写进你自己浏览器的 chrome.storage.local， 永远不会被发送到本项目的任何地方 —— 因为根本不存在这个地方。

事实怎么自己验证
项目没有后端全仓库没有作者名下任何域名
请求直达厂商填谁的门牌就走谁的网关；地址构造只做字符串拼接，唯一的地址来源是你的配置
没有遥测不发统计、不埋点、不上报日志、不检查更新
日志不带密钥请求失败时只截断错误信息，不记录密钥，也不记录请求头

在仓库根目录执行下面这条命令，看它列出的每一个域名：

grep -rhoE "https?://[a-zA-Z0-9.-]+" --include="*.js" --include="*.html" . | sort -u

输出里若出现非厂商域名，请务必先提 issue 问清楚，再考虑要不要用。 安全边界本来就应该是可验证的，而不是靠一句"我保证"。
