先确认这一件事：它只能装在电脑浏览器里，学习通客户端和手机 APP 用不了

Omitone 是一个浏览器扩展 —— 只有浏览器才有「扩展」这个东西。 学习通的电脑客户端、手机 APP、平板 APP 里装不了它，它也不会在那里工作， 不是「没测过」，是那些软件里根本没有可以装扩展的地方。

「扩展」是什么。它是一个装进浏览器里的小程序，装完之后浏览器右上角会多一个按钮。 它不像普通软件那样有安装向导、有桌面图标 —— 它平时是看不见的，只有你点那个按钮，或者打开学习通页面时，它才露面。 所以「装完了却觉得什么都没发生」是正常的。

「压缩包」要解压，是个高频坎。你从网上下回来的那个 omitone.zip 不能直接交给浏览器。要先用鼠标右键点它，解开它，得到一个文件夹。 浏览器要的是那个文件夹，不是压缩包。
右键里那一项各家叫法不一样：Windows 自带的写作「全部解压缩」（有些版本写作「提取全部」）， 装过 7-Zip / WinRAR / 360 压缩 / Bandizip 的机器上多半是「解压到当前文件夹」 「解压到当前位置」或「一键解压」这一族 —— 所以别按字找那一项，按结果认：解开之后眼前第一屏直接摆着 manifest.json，就对了。 只有「添加到压缩文件」那一族是反方向的（那是打包，不是解包），点它只会越点越厚。
Windows 11 上还有一处会卡人：右键菜单默认是收起来的， 先点最下面的「显示更多选项」（或按 Shift + F10），上面那几项才会露出来。 这个文件夹的名字跟着 zip 走：下过一次通常叫 omitone， 下过不止一次可能是 omitone (1)、omitone-1.3.0， 甚至被解压软件丢进 新建文件夹 里 —— 所以别按名字认它，按「打开这一层能不能直接看见 manifest.json」认它。 这一步做错的表现是：浏览器报“清单文件缺失”或干脆没反应。

第 1 步　下载并解压

① 你会看到什么 浏览器打开了项目首页，最上面有两个大链接。左边那个写着 「点我下载插件（omitone.zip）」。
② 点哪里 点它。浏览器会下一个文件，通常是 omitone.zip， 落在你的「下载」文件夹里。
下完之后，用鼠标右键点这个 zip 文件 → 选「解压」那一项。
Windows 自带的写作「全部解压缩」；装了别的压缩软件的，多半写作 「解压到当前文件夹」「解压到当前位置」「一键解压」 —— 字不一样没关系，认结果就行（看下面 ③）。 （Windows 11 的右键菜单是收起来的，先点「显示更多选项」才看得见这几项。）
③ 怎样才算对 解压出来的文件夹里，直接就能看到一个叫 manifest.json 的文件。
（看不到文件后缀？在文件夹里点「查看」→勾上「文件扩展名」。）
④ 不对怎么办 如果你解压后看到的是又一个压缩包，说明你只解开了外面一层，再解压一次。
如果文件夹里是另一个同名文件夹，要进到最里面那一层， 直到眼前直接摆着 manifest.json。
把解压出来的文件夹放到一个你不会随手挪动的位置（比如 D:\omitone\）—— 放桌面然后手滑拖进垃圾桶，扩展就会失效。

第 2 步　打开扩展管理页

① 你会看到什么浏览器顶部那条输入网址的栏。
② 点哪里 点进地址栏，输入下面这串，回车：
用 Edge：edge://extensions
用 Chrome：chrome://extensions
③ 怎样才算对 出现「已安装的扩展」列表页。你现在装过的东西会列在这里， 页面左下角（Edge）或右上角（Chrome）有个开关。
④ 不对怎么办 如果这串地址被当成搜索词搜出去了，说明你没输全、或者多打了空格。完整复制粘贴最稳。
如果你用的是别的浏览器：Firefox 不支持本扩展； 国内套壳浏览器（QQ / 360 / 搜狗）没有开发者模式，也用不了。

第 3 步　打开开发者模式

① 你会看到什么 刚刚那个扩展管理页。页面左下角（Edge）或右上角（Chrome） 有一个叫「开发人员模式 / 开发者模式」的拨动开关，现在是灰的。
② 点哪里点一下那个开关，让它变蓝/变亮。
③ 怎样才算对 页面顶部长出三个新按钮：「加载解压缩的扩展程序」、 「打包扩展程序」、「更新」。
④ 不对怎么办 找不到这个开关，多半是页面没滚到顶 —— 它固定在左上角/右上角。 实在没有，说明你用的不是 Edge 或 Chrome。

第 4 步　加载扩展

① 你会看到什么页面上已经出现「加载解压缩的扩展程序」这个按钮。
② 点哪里 点它 → 弹出一个选文件夹的窗口。这个窗口里「双击」是走进那一层，不是选中 —— 真正算选中靠右下角那枚「选择文件夹」按钮，按下它，选中的是 你此刻正站着的那一层。
① 双击 omitone（或你解压出来的那个文件夹）走进去；
② 此时中间那个列表里应当直接摆着 manifest.json、page.js、libs、popup、icons；
③ 到这一屏就停手，什么也别再双击，直接点右下角「选择文件夹」。
列表里只看见 libs、popup 这些文件夹、 看不见 manifest.json → 你还在它外面那一层，双击进去一次； 已经手快点到 libs 里面去了 → 点窗口上方的「向上 / ↑」退一层， 回到 ② 那一屏再按。
③ 怎样才算对 加载扩展时，列表里多出一张卡片，名字是 Omitone-1.3.1，下面写着 「支持学习通视频播放、API 自动答题」，右下角是「已启用」。
④ 不对怎么办 报「清单文件缺失」→ 九成是往里多点了一层（选中的其实是 libs 或 popup）， 少数是选到了压缩包、或它外面那一层。重新点一次「加载解压缩的扩展程序」， 停在 ② 那一屏（列表里直接看得见 manifest.json）再按。
报「无法加载扩展程序」→ 看看文件是不是被解压软件放进了临时目录 （比如 AppData\Local\Temp），挪到普通目录再试。
报「清单文件无效」→ 文件可能在下载或解压时损坏了，重新下一遍。
装完先确认一件事：它要「在所有网站上运行」是正常的

卡片上会出现这条提示，不要关掉它，也不要觉得这是权限滥用 —— 验证码有时会弹在与学习通无关的独立网址上。 扩展在其它网站上检测到不是目标页面会立刻静默退出，什么都不做。

装完必做的一步：把它的图标钉在工具栏上

Edge / Chrome 默认把新装的扩展收进地址栏右边那枚拼图（⋯）菜单里， 图标本身不显示出来。请把它钉出来：点那枚拼图 → 在列表里找到 Omitone → 点它右边的图钉／「固定到工具栏」， 让 Omitone 的图标常驻在地址栏右边。

为什么要专门做这一步：刷课的入口只有弹窗里那枚蓝色的「开始运行」。 学习通页面上原来还有一张浮在正中间的卡片，带它自己的两个开关（自动连播 / 自动答题）—— 那两个开关只改这一页内存里的设置，不会存下来：刷新一次、跳到下一节， 页面重新读的是弹窗里那一份，卡片上的选择就丢了。两处各说各话，已经整张删掉， 页面里不再有第二个能改设置的地方。 入口只剩弹窗一个，就得保证它随时点得到：图标没钉出来时每次都要先翻拼图菜单， 而页面正在自动翻页、弹验证码的时候，人往往找不到那枚图标， 看起来就成了「插件没反应」。钉在旁边才行。

到这里就装完了。现在去做什么？

打开任意一门学习通课程页面，右下角会出现 Omitone 的吉祥物（弹窗里 「刷课页显示吉祥物」默认开着；关掉她这一页就没有她的影子）。 看到她 = 这一页被扩展认出来了。

接着点工具栏那枚图标 → 弹窗顶部那枚蓝色的「开始运行」，页面右下角才会再冒出 一块状态浮窗，视频自己开始播 —— 到这一步它就在干活了。 视频、文档、PPT、讨论、投票这些不接大模型，不填 Key 也能跑； 但课里的测验 / 作业和验证码是要 Key 的（见第 3 章）。 没填 Key 时遇到测验会跳过不答（这一节会先按住，不会把没做的题说成做完），其余照常。

1. 这是什么，能替你做什么

Omitone 是一个装在浏览器里的扩展。它替你处理学习通网页版里那些 纯粹消耗时间的部分：视频要播完、PPT 要翻到最后一页、讨论区要留一句言、 章节测验要答完。

它不会替你登录，也不会替你发布任何内容 —— 除了你自己开启的讨论区自动回复。 所有数据都在你本机，项目没有任何服务器。

功能说明需要 API Key
视频 / 音频自动播放自动开播、被暂停自动抢回、播完自动翻节不需要
自动最大倍速读播放器菜单取速度上限；问不到最多连问三发，仍问不到就按原速播完这一支不需要
拖到结尾可拖动的视频/音频直接跳到片尾，每一支只判断一次（没跳成最多再补两次）不需要
PPT / 文档 / 图片自动翻页并上报完成不需要
讨论任务点进话题页留一句言 → 自动返回 → 继续刷课；平台已经记成完成的那条不再重复发不需要
投票任务点进投票随手勾第一项提交（它不计分，但仍是任务点）不需要
跳过不必做的点老师没设为任务点的内容直接跳过不需要
题库字体反爬还原学习通用自定义字体加密过的题目文字不需要
乱选（不接 AI）本地随机作答，不保证正确率，只求把卷交出去不需要
AI 答题单选 / 多选 / 判断 / 填空 / 简答 / 视频内弹题需要
验证码识别抓图交给视觉模型识别后自动填入需要（且必须是视觉模型）
没有 API Key 也能刷课 —— 但「题」这一部分要说清楚

上面标「不需要」的功能（视频、文档、PPT、翻页、讨论、投票）装了就能跑，一分钱不花。

测验也有办法：打开设置里的「乱选（不接 AI，随机作答）」， 插件会在本地随机作答、把卷交出去 —— 不保证正确率，但不需要 Key、也不消耗任何 AI 额度。 它的答案不会写进答案记忆：将来你配上 Key 改用 AI 答题，不会被这些随机数据影响。

不开「乱选」也别说它"全都能做"。没有 Key 时遇到测验会跳过不答： 压着题的那一节会先按住不翻页（不把没做的题宣布成已完成）， 按住超过 3 分钟才跳过这一节，并在日志里写明「这些题没做过」；其余照常。

乱选不会一填完就交卷。它把整卷填上之后先停下来，给你默认 30 秒自己看一眼再交 （时长在设置「答题」分组里的「乱选交卷前留几秒检查」改，最长 600 秒； 填 0 就是不自动交 —— 它只负责填，交卷那一下永远由你按）。 交卷不可逆，而乱选的答案是猜的，这几秒就是留给你的。

2. 安装（逐步版）

第 0 章已经走过一遍了。这里是同一件事的详细版： 多讲一些「为什么」和边角情况。已经装成功的同学，直接跳到第 3 章。

  1. 下载并解压 打开项目首页，点最上面那个「下载插件」按钮，会直接下到一个 omitone.zip。 然后右键 → 选「解压」那一项（各家的字不一样，见上面第 0 节），解到一个不会被轻易挪动的目录。
    千万别双击压缩包就直接加载 —— 浏览器要选的是解压后的文件夹， 不是压缩包，也不是压缩包里的预览。解压后的文件夹里应该能直接看到 manifest.json。

装完之后：改代码 / 更新版本要「重新加载 + 刷新页面」

在扩展管理页点一下 Omitone 上的「重新加载」，然后务必刷新学习通页面（F5）。 只重载扩展不刷新页面，页面里旧的脚本会与扩展断连，症状是「功能全停、日志不动」。

3. 第一次配置

打开任意学习通页面，页面右下角会出现一个 Omitone 面板（也可以点浏览器工具栏上的扩展图标打开设置弹窗）。

3.1 设置弹窗长这样

弹窗从上到下分三块：顶部是运行状态和开始/停止； 中间是五个可以折叠的分组（播放、任务点、任务点类型、答题、AI 接入）； 讨论与投票的开关在「任务点类型」里（它们和视频、文档、测验是同一类东西：关掉就不再处理这一类任务点）； 底部是查看日志这类次要操作（「检测 API 连接」在「AI 接入」分组里， 「恢复默认设置」单独压在最底下）。

3.2 怎么知道手里的要不要更新

顶部状态栏下面有一行小字：当前版本（例如 当前版本 1.3.1） ＋ 检测更新。

更新是「覆盖」，不是再装一个新的。 下载的还是同一个 omitone.zip，解压到你原来那个扩展目录里覆盖掉旧文件 —— 位置、设置、密钥、记住的答案都沿用，不会变成第二个扩展。

点「检测更新」，只会有三种结果：

  • 你已经是最新版了 —— 什么都不用做。
  • 有最新版 x.y.z（本地 a.b.c）—— 可能相对现版本不够稳定，是否更新？ 数字只是举例，两个版本号以你屏幕上看到的为准。 点「是，覆盖更新」：插件会自动下载，并在资源管理器里直接帮你选中那个文件； 然后解压覆盖原目录 → 重新加载 → F5。
  • 歪比八布，你的网络或者作者的匿名名额正在睡大觉（别连点，过一会儿再看） —— 就是没查出来： 既不代表你是最新，也不代表你过期。过一会儿再点即可。

版本号一样，为什么还会提示「线上的包比本地新」：作者有时同一个版本号重发一次包（修个小问题，不必让你多下一次）。 这一条只在线上那个包比你手里的新 30 分钟以上时才会出现 —— 刚发布那几分钟不算， 以前它把这几分钟也算成更新，于是装官方 zip 的人几乎总会看到一条误报。

为什么不能一直点：查询走的是 GitHub 的免费额度。手动 6 小时一次、 自动 24 小时一次 —— 点太勤会把额度用光，那时候所有人都查不了。

覆盖之后还要两步才生效：edge://extensions 里点「重新加载」→ 回到学习通页面按 F5。 只重载扩展不刷新页面，旧脚本会和新扩展断连，症状是「功能没反应」。

这一行还会顺手帮你确认一件事：如果你发日志求助，把这一行的版本 + 后面那串字母数字一起截图， 就能确认你装的是哪一份包 —— 省掉一轮「你装的到底是哪版」的来回。

顶部左边还有一个「精简 / 精美」开关，不是功能开关，只是界面档位： 精简只留设置项，最省资源（首次安装默认这个）； 精美会多一个可以拖动的小角色（100 张立绘、15 种动作），纯装饰、不影响刷课。 切换会重新加载弹窗，选过的档位会记住。

为什么预置的模型名会过期？过期了怎么办？

预置里的模型名是钉死的快照，厂商一发新版它就会失效。 失效的表现通常是报「模型不存在」，改「模型名」那一格即可 —— API 地址与协议一般不会变。项目里有一份 docs/channels.md 记录着各家地址、模型名与最后核对日期， 也会定期跟着更新。

不知道模型名叫什么？展开「AI 接入」，点那枚 获取模型列表

「AI 接入」分组里、三处模型名（主模型、看图模型、验证码识别模型）下面 有一枚通栏按钮叫 获取模型列表。点一下，插件就去问那家服务商「你名下有哪些型号」， 把拿到的型号名装进上面三处模型名那几格共用的候选里 —— 点一下输入框就能选，不用再手抄，也照样可以自己打。 预置的模型名过期了（报「模型不存在」），先用这一枚把新名字拿回来最省事。

这一发不花 token：它只问清单，不发消息。旁边那枚 检测 API 连接 才是真发一条消息 （那一发要花钱）—— 想知道「能不能答对题」用那一枚，只想抄型号名用这一枚。

跑的时候按钮文字会变成 获取中…，跑完变回来；结果那句话照实分好几种， 不会统一推给「网络不好」：成功说「已拿到 N 个型号：…」， 地址没填说「还没填 API URL —— 补上再点。」，密钥没填说「还没填 API Key —— 这一步要用它。」， 对方回空的说「这家说自己名下没有可用型号（回包是空的）—— 不是网络问题，也不等于 Key 没用。」， 回包形状认不出来说「回包读不出型号名…」并叫您照旧手填。

3.4b 问模型失败了：弹窗会点名是哪家哪个模型，退不退由你点

① 你会看到什么 点开弹窗，「AI 接入」分组底下多出三行：第一行说错的是哪一类 （余额不足 / Key 无效或无权限 / 模型名或地址不对 / 网络不通）， 第二行写「刚才问的是：Kimi（Moonshot） · kimi-k3」—— 厂牌与模型名都在，不是只有「请求失败」四个字；第三行是一枚键。 没有失败记录时这三行整个藏着，弹窗跟你正常刷课时一模一样。
② 点哪里 要改就走第三行那枚「这一轮改用「乱选」继续」，它就在上面那两行底下； 不想改就什么都不点 —— 这一枚键只在你手上动， 扩展不会因为一家失败了就自己退到乱填，照旧继续问 AI。
那一行点名的是真被问过的那一家：话是照扩展自己存的配置算出来的， 和学习通页面里那一发请求用的是同一把尺（libs/api-error.js）， 所以不会把你指到别家客服去。
③ 怎样才算对 点一下之后键上那句话变成「变回问 AI（关掉乱选）」，同时「答题」那一栏里 那枚「乱选」开关跟着翻过去（再点一次两头一起翻回来）；刷新学习通页面也还是那个状态， 说明真的存到盘上了。不问模型之后，题靠本地兜底做完，钱一分都不花。
④ 不对怎么办 键点下去什么也没翻，弹窗会说一句找不到那枚开关，并给你两条出口：重装扩展， 或者自己到「答题」那一栏手动翻它 —— 它不会假装已经改好了。
认不出是哪家时也不会编：会说「按接入地址认」再加域名；连地址都读不出就写 「(渠道读不出)」，模型名没填就写「(模型名没填)」—— 两格各说各的， 绝不压成一句「没有这回事」。

3.5 思考强度：三个场景各设上下限，默认关掉

弹窗里「思考强度」现在是三行 × 两格： 刷课（视频与页面任务点的普通问答）、测试（章节测验与视频里弹出的题）、 考试（标题带「作业」或「考试」的整份卷子），每行一个「下限」一个「上限」， 取值都是 关闭 / 低 / 高。六格默认全是「关闭」 —— 那和升级前一字不差， 一个请求都不会变。

下限 = 至少想到这一档；上限 = 最多花到这一档。 两格拉开（比如「关闭—高」），中间那一档交给模型自己定： 它按题目难度自己决定想多深，我们只把成本的上限钉住 —— 钱按上限备额度，不替它决定每一发都想满。 两格收成同一档（比如「高—高」）就是固定档，每一发都想那么深。 选倒了（下限高于上限）会当场把两格收齐，不会写出一个空区间。

怎么选给厂商发什么什么时候选它
关闭—关闭（默认，两格同一档） DeepSeek 发 thinking:disabled；通义发 enable_thinking:false； Kimi 什么都不发（它关不掉）；认不出的渠道也不发任何参数 几乎总是选它。答题是模式化任务，不需要推理 —— 实测一次请求从 361 token 降到 133，又快又省
同一档（低—低 / 高—高） 固定档，reasoning_effort 一类字段按那一档发死 你明确知道要那么深，或明确不要超过那么深。 「高」每道题都会先烧掉一大段推理 token，账单会明显变高
拉开两格（关闭—低 / 关闭—高 / 低—高） DeepSeek 这一家反而什么都不发 —— 那正是「让它自己定」； 没有自选写法的渠道退成按下限发，弹窗那行会照实说 想要「难一点的题多想、简单的别多想」又不想逐题盯着 —— 上限就是成本的闸门
诚实说明：只有「关闭」是实测过的，拉开两格这一族还没验证

三档里只有「关闭」在本项目一直被真实使用（那是升级前的唯一行为）。 「低」「高」的参数是照各家官方文档写的，没有在真实题库上验证过： 有的服务商会直接拒绝不认识的参数。真被拒绝时程序会 自动摘掉参数重试一次并把原因写进日志，不会让答题功能整个失效 —— 但既然没必要多花钱，默认关着就好。

另外 Kimi K3 是恒思考模型，关不掉。选「关闭」不会报错，但它仍然会推理。

这三行差别肉眼看不见，所以下面那段「当前实际发送」会把每一行真发出去什么 原样写出来，并标上「已实测」还是「未验证」—— 弹窗说的是你手上此刻的选择， 动一格就跟着变。跑过一阵之后，还会补一句 「上次它自己想到「低」（约 N 推理 token）」：那是从回包的推理 token 反推的， 读不到就整句不说，不会把「没读到」讲成「它从没思考过」。

那三行逐字长这样（左边是渠道，右边是这一档真发出去的东西）：

  • DeepSeek · 测试思考=固定档 off · {"thinking":{"type":"disabled"}} · 已实测
  • DeepSeek · 测试思考=[off,high] 交给模型自选 · 不发参数 · 未验证
  • Kimi（Moonshot） · 测试思考=固定档 off · 不发参数 · 未验证（该渠道关不掉思考，实际仍会推理）

「交给模型自选」= 上下限拉开了，中间那一档由它按题目难度自己定； 「不发参数」= 这一家只按官方文档写着、一个字段都不发（认不出的渠道一律如此，免得被 400）； 最后那个括号是它本来关不掉思考 —— 所以看见「固定档 off」不等于它没在推理， 想知道开没开，只看参数发没发出去会判错。

3.5.1 「考试」那一行为什么单独一行

整份卷子（作业 / 考试）和零散问答的代价不一样：答错一格就是真错了， 事后没有「再问一次」的余地。所以它单独占一行。

考试那行的下限选「高」，模型没答上来的题，扩展会停下来等 （下一拍重问，或者你手动作答后自动提交），不拿猜测占位交卷 —— 宁可这一节慢一点，也不把没做对的题说成做完。 视频里弹出的那道选择题归「测试」那一行管，兜底逻辑和以前一样。

升级前那个单独的「整卷思考强度」下拉框已经被这三行取代 —— 老值会自动搬过来：原来全局档设成「高」，升级后三行的上下限都是「高」； 原来「整卷档=高」，升级后只有「测试」「考试」两行抬到「高」，刷课照旧。 不用重设。

3.6 弹窗里的每一枚开关，逐个说清

设置弹窗里一共有 20 枚开关，分在五个折叠分组里。 下面这张表把界面上一行行的原话抄下来，你对着找就行，不用猜哪个是哪个。

先看「出厂」那一列：绝大多数情况一个都不用动。 这一页是给你遇到对应症状时按图索骥用的 —— 比如「视频统计不动」先去查静音， 「明明刷完了平台却说没完成」去看已完成任务重学。 开关的作用域互不重叠：关掉某一枚，只会让它管的那件事停下来，不会影响别的。

3.6.1 「播放」分组（5 枚）

界面上那一行出厂它管什么 · 什么时候动它
自动倍速（跟随视频最大倍速）开 读播放器自己的倍速档位，取它能支持的最快那一档。没有手动的「播放速度」档了 —— 往播放器上写倍速这个动作本身，在被站点按住的视频上就会抽搐、黑屏，所以只能跟着播放器能给的走。
读不到上限时最多连问三发，还问不出就这一支按原速播完（换下一支再问）， 不会每 1.5 秒反复试一遍。
什么时候关：你怀疑倍速把站点惹毛了（它把你按回 1x、或者记不上进度）， 关掉它就只按正常速度播 —— 慢，但最不像作弊。
兼容慢机（低配 / CPU 高负载时放宽等待）自动 出厂是「自动」：扩展自己看这台机器忙不忙，忙就放宽等页面加载、截图、扫描的等待时间。
什么时候开：老电脑 / 一边开着别的重活，日志里出现「等了一会儿还没长出来」这类话。
可拖动的视频/音频直接拖到结尾开 进度条能拖的那些，直接把播放位置拉到片尾，每一支只判断一次（第一次没跳成最多再补两次， 仍不成就不再动这一支）；试完不成就老实用原速播。
什么时候关：你宁可慢一点也不想让它跳进度（有些课会因此不认）。
它还喂着下面那一枚：关掉它就等于不再动手试拖，「拖不动」这个信号只剩两条 —— 站点写在卡片上的那句「当前视频不可拖拽」，以及同一门课里已经认过的那一回 （那一本账本来就是从这两条里攒起来的，动手试那一路被关掉后攒不到新账）。 这两条读得到，下面那一枚照样生效； 两条都没有时，下面那一枚会明说「被放弃了」，不会悄悄失灵（弹窗里那一行会当场说明这一点）。
防拖拽视频看到 90% 就进下一个开 管的是拖不动的那一族：站点不许跳进度，那就老老实实播，看到 90% 就进下一条 —— 站点的完成线写在「≥90%」，最后那 10% 不改变结果。
什么时候关：某一门课要看到 100% 才算，就把它关掉，让它播到底。
「拖不动」的证据有三个来源：站点自己在卡片上写的那句话（读得到就不用动手试， 上面那枚关着也生效），真的试一次拖到结尾被弹回两次（那一枚开着才有）， 或者同一门课里已经认过一回（这一门里别枚视频攒下的那一回，后面每一枚直接照它办 —— 它只会让扩展少动手，绝不替这一支多拖一次；这一本账记在当前这个标签页上， 刷新那一页不会把它清空，换一枚标签页或关掉学习通才会重新学，隔一阵还会再挑一枚试一次）。 三个来源都拿不到时这一枚不会硬猜，日志里会说一句「被放弃了」； 它也从不为了拿证据而多动手试一次。
静音关 开着它视频就没有声音。
什么时候动：想安静刷课就开；反过来如果开了它进度反而不涨， 说明这一门课要页面真出声才算在看 —— 关掉它。

3.6.6 「已完成任务重学」这一枚，什么时候真的要用

它不是「让它多刷几遍」，是进度被收回时的补救

正常情况下这一枚就该关着：跳过已经完成的点，是刷课快起来的主要原因。

要开它的只有一种情况：你确认这一门的进度被平台收回去了 —— 昨天明明刷到 100%，今天回来看它掉回一截；或者扩展一路说「已完成，跳过」， 可平台上那一节还是灰的、不计完成。这时候打开它， 扩展会把那些写着「已完成」的任务点重新走一遍，让平台重新收下一遍记录。

代价说清楚，别开着不管：视频会重看（占时间）、题会重新问一遍（再花一次钱）； 而且它一直有活干，「刷完自动换下一门」就可能永远等不到尽头。 所以这一枚的用法是：这一门补完就回头关掉。

日志里那句 restudy enabled, skip-completed disabled 就是它生效的证据 —— 有这句话，说明「跳过已完成」这件事确实被关掉了。

4. 开始刷课

这一步是整个工具的主干。装好、配好之后，剩下的时间它都在做这件事。

① 你会看到什么 浏览器里已经打开了某门课的章节页面。点扩展图标，弹窗顶部写着 「未开启」，那个小圆点是灰的。
② 点哪里 先确认「播放」和「任务点」这两组里的开关保持默认（开着的）， 然后点顶部那个蓝色的「开始运行」。
③ 怎样才算对 两处同时变化：
① 弹窗顶部那颗灰圆点变绿，旁边的字由「未开启」变成 「已开启」；
② 学习通页面右下角冒出一个状态浮窗。
然后视频自己开始播 —— 到这一步它就在干活了。
④ 不对怎么办 点了没反应、圆点还是灰的 → 最常见的两种： 没刷新学习通页面（按 F5），或者当前页面根本不是课程页 （在首页、作业页、考试成绩页它是不会启动的）。
圆点绿了但视频不动 → 点「查看日志」，看最后几行有没有报错， 拿日志里的原话去第 7 章对照。
开始之后又自己变回「未开启」 → 多半是页面被跳转/刷新过， 扩展会重新接管，稍等十几秒；一直不行就刷新页面重来。
  1. 打开课程页面进入你要刷的那门课，停在章节列表或任意一节课里。
  2. 点扩展图标 → 确认开关 → 点「开始运行」右下角会出现状态浮窗。
  3. 然后就可以去干别的了它自己会：播放视频 → 做文档 → 答题 → 下一节。
  4. 想停就点「停止」或者直接关掉标签页。

浮窗的第二行会写 执行任务：××。那个 ×× 只会是下面九个词之一 —— 认出它是哪一个，就知道这一会儿它在做哪一类任务点。

浮窗第二行它此刻在做什么

4.1 刷完一门之后：会自己回用户中心挑下一门

以前它刷到最后一节就停着不动了。现在多了尽头判定： 插件看的是章节目录上每一节有没有打完成勾（就是课程页左边那一列， 打勾的那一节站点点的是 icon_Completed）。 只有目录里每一节都打了勾，它才认「这一门刷完了」—— 只要还剩一节没勾（哪怕是「还没解锁」的那一节），它就不换课，继续往前推。

认定刷完之后，它会回用户中心，从你自己的课程列表里挑下一门（进去之后原来那套管线照常跑， 站点落在哪一节就从哪一节开始）。挑法分两层：

  1. 先看卡片上写了「任务点进度 a/b」的那些 —— 取 a<b 里进度跑得最远的那一门， 不是列表里第一张卡片：先把开了头没学完的收尾，免得每门都开个头停在半路。
  2. 那一行读不到的，不再叫你自己去点（实测这样的课占了一大半，卡片上只有课名和老师名， 站点压根没写进度）。这一族里挑一张进去让章节目录判：目录里每节都有勾， 它一个任务点都不做、一次 AI 请求都不发就原样退回来换下一门； 有没勾的小节，就从站点落的那一节开始推。

卡片上没写进度那一族，进去之前还多一步：插件先在后台挨门读一遍站点自己的课程首页 —— 一轮最多问 40 门，单页最多 12 秒、整轮最多 20 秒封顶， 只读网页内容（不动正在播的那一枚学习页，也不新开标签：同一账号开第二枚会把前一门顶下线）。 问到的进度按「还要刷 → 读不出 → 没有任务点 → 已完成 → 进不去 → 目录为空」给这几门排队， 只改挑谁的顺序，一门都不会因为这一读被删掉（首页那个数会过期， "站点说刷完"不等于把这门锁上）；同一门的答案 30 分钟内不重问。 挑的那一拍最多为它等 24 秒，到点还没问完就照手里已有的进度先进一门、让目录判 —— 不会因为"还在问"把换课钉死在用户中心那一页。

这个行为由「任务点」分组里的「刷完自动换下一门」控制，默认是开着的。 关掉之后，刷完最后一节就停在那一节不动，日志会写清楚是"开关关着所以停"。

三件事它不会做
  • 不猜读不到进度的课。用户中心有些卡片上压根没有「任务点进度」那一行， 在卡片上读不到就等于没有依据 —— 它不在卡片上猜做没做完， 而是先读一遍站点自己的课程首页给这几门排队，再进去问目录 （判据始终是目录上的完成勾，不是卡片或首页那一行）。 日志与右下角都会写清这一门是这样进去判的，不是按进度挑的。
  • 不替你手动打开的页面做主。你要是自己点进用户中心逛，它一步都不做； 只有它自己为了换课导航过去的那一页才会挑课。
  • 不跳章。站点自己规定「需完成之前闯关任务点，该章节才可解锁」， 所以它一节一节往前推，不用地址硬闯没解锁的章节。

另外有两道防"来回空转"的闸：60 秒之内不会重复换课， 而且一轮连续刷课最多换几门，按你用户中心里能进的课来给，最少 30 门（六小时重新起账， 真正防来回空转的是名单：同一门六小时内只进一次）。 到上限了日志会直说，想继续就手动进下一门，或者关掉再打开刷课重新起账。

这一段动作发生时，右下角浮窗第二行只会是下面三个词之一 —— 认得出这三个，就不用点开日志也知道它走到哪一步了。

浮窗第二行它此刻在做什么
这一门刷完了 目录每一节都打了勾。后面那句详情会分两种：正在回用户中心（它自己接着办， 状态点是等待中），或者「刷完自动换下一门」是关的，所以停在这里 （状态点变注意，这一步要你拿主意）。
进入下一门 用户中心已经挑好了下一门，正跳进去（详情里那对数字是本轮换课第几次 / 上限）。 进去之后原来那套管线照常跑。
刷完不换下一门 刷完了但没法自动接着换：要么这一次换课到上限了，要么能读到进度的课都刷完了。 这不是故障，详情里会写清楚是哪一种，请手动挑一门。

5. AI 答题是怎么工作的

理解这四步，你就知道它能做到什么、做不到什么：

  1. 抠题从页面 DOM 里把题干、选项、题型读出来。遇到字体反爬会先还原文字。
  2. 问模型把题目按 10 题一批打包发给你自己填的那个 API 地址，要求模型只回一个答案数组。
  3. 回填把答案写进页面选项与隐藏答案域。
  4. 交卷检查所有题都填上了才提交；判错会带着「已排除的错误答案」再来一轮。

5.1 关于正确率（重要）

AI 答题做不到全对，考试请不要用
  • 提示词要求「不确定也要给最可能的答案」，所以模型会猜，猜错就是真错。
  • 答错后会自动重试，但默认最多尝试交卷 20 次 —— 而这些提交是真的会交上去的。 如果这门课限制了提交次数，请先确认规则。
  • 判断题、多选题的出错概率明显高于单选题。
  • 五种题型（单选 / 多选 / 判断 / 填空 / 简答）都发给 AI 作答。 插件只在AI 那份没能填进页面时才用本地兜底补一个，补出来的完全是猜的、 正确率没有保证；那种「靠猜补过」的卷子自动重交最多 2 次（首发 + 一次认真重做）， 不像普通卷子那样最多试 20 次 —— 猜的答案过不了的卷子，再交多少次都过不了， 而每一次提交都是真的交上去。
  • 成绩重要的测验，请在弹窗里关掉「自动答题」自己答。 这个工具的价值在于省下刷视频的时间，不在于替你拿分。

5.2 怎么知道钱花在哪了

日志里会出现 llm prefix cache hit:… miss:… 这样的记录。 DeepSeek 对重复出现的提示词前缀有缓存，命中部分按约十分之一的价格计费。

① 你会看到什么 日志里形如 llm prefix cache hit:180 miss:120 的行。
hit = 走了缓存（便宜）的 token 数； miss = 没走缓存的 token 数。
② 点哪里不用点，它自己会记。看日志时留意这一行就行。
③ 怎样才算对 hit 是个明显大于 0 的数字（比如 180 hit : 120 miss）， 说明省钱机制在工作 —— 那一部分按十分之一计价。
④ 不对怎么办 先看 miss 有多大。缓存是按一整块（256 token）起的， 题目少、一次只问一两题的那种请求，整份输入还凑不满一块 —— hit:0 miss:1xx（日志里带 belowBlock:256） 是正常的，它压根没有可复用的前缀，不代表任何毛病。
要留意的是大请求也一直 hit:0（比如 miss 上千）， 那才说明前缀没被缓存识别 —— 通常意味着提示词被改动过（把每次都变的内容放到了前面）。 这是 1.1.0 专门修过的问题，日志留在这里就是为了让你能一眼看出来。
只是账单偏高、但 hit 正常 → 看看这三行的上限是不是抬到了「高」： 钱按上限备额度，所以就算中间那一档交给模型自己定，上限是「高」就仍按「高」计； 两格收成「高—高」更是每道题都先烧一大段推理 token。

6. 验证码

学习通会在检测到异常行为时弹验证码。开启「验证码自动识别」后，扩展会抓图、 交给视觉模型识别、再填进去。

  • 默认留空就行 —— 主模型本身带看图。只有你把主模型换成纯文本模型时， 才需要另填一个视觉模型名（如 gemini-flash-latest、qwen-vl-max）。
  • 识别并不总准，会重试，也可能识别错 —— 错了就是白跑一轮。
① 你会看到什么 学习通页面上突然弹出一个小窗口，里面是一张歪歪扭扭、带干扰线的字母数字图， 下面有个输入框。
② 点哪里 你不用点 —— 前提是你在「答题」分组里开了 「自动识别验证码」，并且填了「验证码识别模型」。 开了之后它会自己抓图、识别、填进去。
③ 怎样才算对 验证码窗口自己关掉，课程继续往下走， 日志里出现识别相关的记录。到这一步就是成功了。
④ 不对怎么办 它一直重试、填不对 → 大概率是「验证码识别模型」留空或填错了 —— 默认主模型带看图、留空即可；把主模型换成纯文本模型后，就必须单独填一个能看图的。
它试了几次就不管了、页面也不再自己刷新 → 这是故意的：同一个验证码最多刷 3 轮页面， 之后停手 30 分钟（每一次识别和每一次刷新都是真金白银，也是在给平台递证据）。 这段时间里请你亲手在页面上输一次，输完就继续。
你自己手动填一次 → 最快。填完继续刷课即可。
验证码越来越频繁 → 见下面的警告框，别硬刚。

验证码窗口是从哪来的，决定要不要你点一下：

  • 从学习通页面自己弹出来的 —— 扩展会自动接管，你什么都不用点。 这个授权只对那一个网址有效，10 分钟后自动失效，换页就作废。
  • 你从收藏夹、地址栏或别人发的链接直接打开的验证码页 —— 扩展不会自作主张。 回到弹窗点一次「仅授权当前页验证码」就行，同样 10 分钟有效。
验证码频繁出现，说明平台已经在关注自动化行为了

这时候最稳妥的做法是停一会儿，手动做几题，而不是继续硬刚。 继续跑只会让风控升级。

③ 是不是卡在标题含「作业 / 考试」的章节不动。

还剩两档是插件绕不过的： ① 睡眠标签页是整页冻结 —— 去 edge://settings/system 把它关掉； ② 浏览器没给这一页播放授权时，会把这条保活音频直接拒掉（日志出 audio keepalive stayed suspended）。这种情况回到这一页随便点一下空白处 —— 浏览器要的就是这一下 —— 再看那条记录还出不出。
视频开头黑屏 / 画面抽搐不动 很多人反映「自己点一下开始就好了」—— 现在插件会代点：自动唤醒连续 3 次都点不亮时， 帮你按下播放器自带的「开始」键（同一节最多试 2 次、间隔约 45 秒，且只在还停在开头时才动手）。 点过了日志会出 media start stuck, clicked site start control； 试完仍不行会出 media start stuck, left to human —— 这时请亲手点一下「开始」或按 F5。 反复出现的话，顺手去 edge://settings/system 看一眼效率模式： 它给后台页面省资源，最容易被卡的正是开头这一段。
某个任务点一直做不完 多看日志：遇到老师设成防拖拽 / 不可翻页的点，连续几次做不完会被记入「放弃名单」。
讨论区发了「1」 默认回复内容就是 1，请务必改成正常的话 —— 一串 1 在老师眼里就是灌水。

表现就是播过 90% 还在原速继续播到结尾。想让它提前收尾，把那枚开关打开，让它自己试出来； 同一支只说一次，不会每几秒钟刷一条。括号里的 ratio / duration 是当时的播放位置和总长。

看到这一句说明已经自愈，不用你动手。括号里 reason 说它是从哪条链路补的 （ocs-runner-active-job = 正常的章节页；ocs-style-active-job = 页面结构换过、任务点直接挂在外面那一类课），currentTime / duration 是补回来那一刻的位置和总长。偶尔一条是正常现象；要是同一节课里一条接一条地出， 说明有什么在反复掐掉它，把这一句连同「哪门课 · 哪一节」一起反馈。

8. 密钥安全：为什么说它偷不走

做这种工具最该被追问的就是这句话。所以把结论和你可以自己验证的方法都放在这里。

结论

密钥只写进你自己浏览器的 chrome.storage.local， 永远不会被发送到本项目的任何地方 —— 因为根本不存在这个地方。

事实怎么自己验证
项目没有后端全仓库没有作者名下任何域名
请求直达厂商填谁的门牌就走谁的网关；地址构造只做字符串拼接，唯一的地址来源是你的配置
没有遥测不发统计、不埋点、不上报日志；只有你在弹窗里主动点「检测更新」时才会访问 GitHub 的公开接口
日志不带密钥请求失败时只截断错误信息，不记录密钥，也不记录请求头

在仓库根目录执行下面这条命令，看它列出的每一个域名：

grep -rhoE "https?://[a-zA-Z0-9.-]+" --include="*.js" --include="*.html" . | sort -u

输出里若出现非厂商域名，请务必先提 issue 问清楚，再考虑要不要用。 安全边界本来就应该是可验证的，而不是靠一句「我保证」。
