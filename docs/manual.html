1. 这是什么，能替你做什么

Omitone 是一个装在浏览器里的扩展。它替你处理学习通网页版里那些 纯粹消耗时间的部分：视频要播完、PPT 要翻到最后一页、讨论区要留一句言、 章节测验要答完。

它不会替你登录，也不会替你发布任何内容 —— 除了你自己开启的讨论区自动回复。 所有数据都在你本机，项目没有任何服务器。

功能说明需要 API Key
视频 / 音频自动播放自动开播、被暂停自动抢回、播完自动翻节不需要
自动最大倍速读播放器菜单取速度上限；读不到就逐档试探不需要
拖到结尾可拖动的视频直接跳到片尾，每个视频只试一次不需要
PPT / 文档 / 图片自动翻页并上报完成不需要
讨论任务点跳转讨论区 → 自动回一句 → 返回继续刷课不需要
跳过不必做的点老师没设为任务点的内容直接跳过不需要
题库字体反爬还原学习通用自定义字体加密过的题目文字不需要
AI 答题单选 / 多选 / 判断 / 填空 / 简答 / 视频内弹题需要
验证码识别抓图交给视觉模型识别后自动填入需要（且必须是视觉模型）
没有 API Key 也完全能用

上面标"不需要"的功能装了就能跑。没有 Key 时遇到测验会跳过不答，其余照常。

2. 安装

扩展没有上架应用商店，需要在浏览器里手动加载。整个过程两分钟。

  1. 下载并解压 从项目 Release 页面下载 omitone-1.1.1.zip（或 Source code），解压到一个 不会被轻易挪动的目录。解压后的文件夹里应该能直接看到 manifest.json。
  2. 打开扩展管理页 Edge 输入 edge://extensions；Chrome 输入 chrome://extensions。
  3. 打开开发者模式 页面左下角（Edge）或右上角（Chrome）的「开发人员模式 / 开发者模式」开关。
  4. 加载解压缩的扩展程序 点该按钮，选中解压出来的那个文件夹（里面直接就是 manifest.json 与 page.js）。选中后列表里会出现 Omitone。
  5. 确认它要"在所有网站上运行"是正常的 这不是权限滥用 —— 验证码有时会出现在与学习通无关的独立网址上。 扩展在其它网站上检测到不是目标页面会立刻静默退出，什么都不做。
装完之后：改代码 / 更新版本要「重新加载 + 刷新页面」

在扩展管理页点一下 Omitone 上的「重新加载」，然后务必刷新学习通页面（F5）。 只重载扩展不刷新页面，页面里旧的脚本会与扩展断连，症状是"功能全停、日志不动"。

3.2 拿到一个 API Key

  1. 去 DeepSeek 开放平台注册 打开 platform.deepseek.com，注册并登录。
  2. 充值一点点就够 这个工具每次答题消耗的是输入 token 为主，一节测验通常只花几分钱。 充 10 元能用很久很久。
  3. 创建 API Key 在「API keys」页面新建，复制那串 sk-…。 它只在创建时显示一次，复制好再关页面。
  4. 回到扩展弹窗，粘贴进去 输入框失焦后会自动保存，不需要再点别的按钮。粘贴时带上引号或 Bearer 前缀也没关系，会被自动清洗掉。
  5. 点「检测 API 连接」 看到成功提示说明通路正常。这一步别跳过 —— 它是唯一能在真正答题前发现问题的机会。

3.3 想用别的模型怎么办

「接入方式」里只预置了真正实测通过的服务商： DeepSeek（唯一在真实答题里完整验证过）、Anthropic Claude、 Google Gemini（后两者协议已适配，但没在真实题库上跑过）。

用别家（通义 / 智谱 / Kimi / OpenRouter / 硅基流动 …）请选 「自定义 OpenAI 兼容」，把官方文档上的 API 地址与模型名自己填进去。

为什么不像别的工具那样内置十几种厂商？

内置的厂商预置里，模型名是钉死的快照。厂商一发新版，预置就失效 —— 而用户是照着下拉框一路填完，最后才发现用不了。 这比留空白更坑人，所以现在只留实测过的，其余交给"自定义"。

4. 开始刷课

  1. 打开课程页面进入你要刷的那门课，停在章节列表或任意一节课里。
  2. 点扩展图标 → 确认开关 → 点「开始运行」右下角会出现状态浮窗。
  3. 然后就可以去干别的了它自己会：播放视频 → 做文档 → 答题 → 下一节。
  4. 想停就点「停止」或者直接关掉标签页。
出问题先看日志

点扩展图标 →「查看日志」，里面是最近 200 条运行记录。 90% 的问题看一眼日志就能定位，比反复猜测快得多。页面右下角浮窗只有摘要， 想看全的就去日志面板。

5. AI 答题是怎么工作的

理解这四步，你就知道它能做到什么、做不到什么：

  1. 抠题从页面 DOM 里把题干、选项、题型读出来。遇到字体反爬会先还原文字。
  2. 问模型把题目按 10 题一批打包发给你自己填的那个 API 地址，要求模型只回一个答案数组。
  3. 回填把答案写进页面选项与隐藏答案域。
  4. 交卷检查所有题都填上了才提交；判错会带着"已排除的错误答案"再来一轮。

5.1 关于正确率（重要）

AI 答题做不到全对，考试请不要用
  • 提示词要求"不确定也要给最可能的答案"，所以模型会猜，猜错就是真错。
  • 答错后会自动重试，但默认最多尝试交卷 20 次 —— 而这些提交是真的会交上去的。 如果这门课限制了提交次数，请先确认规则。
  • 判断题、多选题的出错概率明显高于单选题。
  • 成绩重要的测验，请在弹窗里关掉「自动答题」自己答。 这个工具的价值在于省下刷视频的时间，不在于替你拿分。

5.2 怎么知道钱花在哪了

日志里会出现 llm prefix cache hit:… miss:… 这样的记录。 DeepSeek 对重复出现的提示词前缀有缓存，命中部分按约十分之一的价格计费。

如果你看到 hit:0 一直不变，说明前缀没被缓存识别 —— 那通常意味着提示词被改动过（把每次都变的内容放到了前面）。 这是 1.1.0 专门修过的问题，日志留在这里就是为了让你能一眼看出来。

6. 验证码

学习通会在检测到异常行为时弹验证码。开启「验证码自动识别」后，扩展会抓图、 交给视觉模型识别、再填进去。

  • 必须另填一个视觉模型名（例如 gemini-flash-latest、 qwen-vl-max 这类支持图片输入的模型）。留空会退回主模型， 大概率识别失败。
  • 识别并不总准，会重试，也可能识别错 —— 错了就是白跑一轮。
验证码频繁出现，说明平台已经在关注自动化行为了

这时候最稳妥的做法是停一会儿，手动做几题，而不是继续硬刚。 继续跑只会让风控升级。

7. 常见问题排查

症状先查什么
点了开始，什么都不动 先确认是不是没刷新页面（只重载了扩展）。刷新学习通页面再看日志第一行有没有 start。
AI 一直读不到题 ① 日志里有没有 quiz scan found 0 questions；
② 密钥是否真的保存上了（最常被忽略 —— 确认「检测 API 连接」能过）；
③ 是不是卡在标题含「作业 / 考试」的章节不动。
答案填了但不交卷 通常是有题没填上。看日志末尾几行有没有 answers are not ready。
视频里的弹题卡住不动 看日志里有没有 popup quiz unanswerable —— 那是"认不出的弹题模板，已放弃"。 这类题最多问 3 次就放手，课程会继续，不会卡死。
题干显示成乱码 立刻停手。这是题库字体反爬表过期了，乱码喂给 AI 必然答错，还白烧 token。
窗口最小化后几乎不动 浏览器自己的「睡眠标签页」是整页冻结，插件绕不过。去 edge://settings/system 关掉它。
某个任务点一直做不完 多看日志：遇到老师设成防拖拽 / 不可翻页的点，连续几次做不完会被记入"放弃名单"。
讨论区发了「1」 默认回复内容就是 1，请务必改成正常的话 —— 一串 1 在老师眼里就是灌水。

7.1 给愿意动手的人：页面控制台诊断命令

在学习通页面按 F12，在控制台里可以直接查现场：

命令作用
xxtAI.diagnose()题目扫描诊断：每个框架命中了什么选择器、为什么没抠出题
xxtAI.scanQuiz()只跑一次抠题并打印结果（不答题、不提交）
xxtAI.diagnosePopup()弹题诊断：弹窗结构、抠到几个选项、推断出的字母
xxtAI.taskGiveUpList()哪些任务点被判"做不完"而放弃了
xxtAI.clearTaskGiveUp()清空放弃名单，让它重新尝试
xxtAI.next() / xxtAI.skipQuiz()手动跳到下一节 / 跳过当前答题

想让开发者修问题，把 xxtAI.diagnose() 的输出、页面地址、扩展版本号一起提上去， 比"用不了"三个字有效得多。

8. 密钥安全：为什么说它偷不走

做这种工具最该被追问的就是这句话。所以把结论和你可以自己验证的方法都放在这里。

结论

密钥只写进你自己浏览器的 chrome.storage.local， 永远不会被发送到本项目的任何地方 —— 因为根本不存在这个地方。

事实怎么自己验证
项目没有后端全仓库没有作者名下任何域名
请求直达厂商填谁的门牌就走谁的网关；地址构造只做字符串拼接，唯一的地址来源是你的配置
没有遥测不发统计、不埋点、不上报日志、不检查更新
日志不带密钥请求失败时只截断错误信息，不记录密钥，也不记录请求头

在仓库根目录执行下面这条命令，看它列出的每一个域名：

grep -rhoE "https?://[a-zA-Z0-9.-]+" --include="*.js" --include="*.html" . | sort -u

输出里若出现非厂商域名，请务必先提 issue 问清楚，再考虑要不要用。 安全边界本来就应该是可验证的，而不是靠一句"我保证"。

9. 使用边界（请务必读）

用途限定：仅供学习与技术交流。用于"作弊"的一切风险，由你自己承担。
  • 本工具的定位是"学习辅助"，不是"替你完成学业"。 它适合的是那种"看了三遍还是这几句话、纯粹在消耗时间"的部分 —— 把这段时间还给你，去做真正需要动脑的事。
  • 如果你用它来完成本应独立完成、且计入考核的作业或考试，那就是作弊。 这是你的选择，不是开发者的建议。
  • 由此产生的一切后果 —— 成绩作废、课程挂科、纪律处分、学籍影响 —— 全部由使用者本人承担。
  • 请遵守你所在学校的规章制度与学习通的用户协议。 不同学校、不同课程对自动化工具的容忍度差别很大，你比谁都清楚边界在哪。

9.1 它不会做的事

  • 不会代替你输入账号密码
  • 不会代替你发布任何内容（除了你自己开启的讨论区自动回复，且默认内容需要你改）
  • 不会把任何数据传到外部，除了你自己配置的模型接口
