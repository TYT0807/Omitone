AI 接入需要 API Key

推荐用 DeepSeek：便宜、快，而且是唯一在真实答题链路上实测通过的。 其余渠道的地址与模型名是照厂商文档填的快照，厂商换版就会失效 —— 失效了照新文档改「模型名」那一格即可；用表里没有的服务商就选 自定义 OpenAI 兼容，URL 与模型名自己填。
怎么拿到密钥：见根目录 《使用说明.pdf》 的「申请 API 密钥」一节。

「关闭」是唯一实测过的档位，也是本项目一直以来的行为 —— 答题是模式化任务，实测关掉后一次请求从 361 token 降到 133。 另外两档照厂商文档填写，未在真实题库验证，个别服务商会直接拒绝； 真被拒绝时程序会自动摘掉参数重试一次，并把原因写进日志，不会把整次答题判死。

只有明确知道自己在做什么时才填。内置那版是压过的， 换成长提示词会让每次请求都更贵；填错格式也不会导致解析失败（有兜底）。
